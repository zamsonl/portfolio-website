FROM BEHAVIOUR TO DETECTION

The rule it produced

Watching that beacon arrive in Wazuh is how I wrote the detection for it. One rule notices a single outbound connection to the tunnel edge. A second says that six of them in a minute from the same source address is a pattern, not a coincidence.

I mapped it to the ATT&CK techniques for a command-and-control channel over a web protocol, so it lines up with the rest of the coverage.

The first rule alone is noise. The frequency rule is the one that means something.
