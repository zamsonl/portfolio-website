# Zamson Lim — Portfolio

Live website: https://zamsonl.github.io/portfolio-website/

A responsive dark portfolio covering malware research, development and analysis, detection engineering, and SOC experience. Built with HTML, CSS and JavaScript.

## Publishing

GitHub Pages publishes the main branch from the repository root. No build step is needed. Push changes to main to update the live site.

## Local preview

Open index.html, or run `python -m http.server 4173` and visit http://localhost:4173.

The SOC demos use simulated data.
